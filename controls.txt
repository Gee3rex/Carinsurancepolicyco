A fancier version of this can be found here: https://sandboxels.r74n.com/controls

[Sandboxels Controls]
Left Click         =  Place Pixels
Right Click        =  Erase Pixels
Middle Click       =  Pick Element
Space / P / K / `  =  Pause Simulation
Shift + Heat       =  Intense Heating
Shift + Cool       =  Intense Cooling
Shift + Mix        =  Include Fire, Smoke, and more in Mixing
Shift + Shock      =  Intense Shock
Shift + Smash      =  Intense Smash
Shift + Mouse      =  Draw Line
Scroll             =  Change Cursor Size
- or [             =  Decrease Cursor Size
+ or ]             =  Increase Cursor Size
Shift + -          =  Set Cursor Size to 1
Shift + +          =  Increase Cursor Size
Left/Right Arrow   =  Change Category
E or / or I        =  Element Search
\                  =  Settings Menu
L                  =  Save & Load Menu
M                  =  Mod Manager
R                  =  Reset Canvas
Alt + Shift + R    =  Refresh and Reload Scene
>                  =  Step
F or F11           =  Toggle Fullscreen
1 or 0             =  Normal View
2                  =  Thermal View
3                  =  Basic View (No Effects)
4                  =  Streak View
5                  =  Outline View
H                  =  Hide Canvas
T                  =  Change Speed (TPS)
F1                 =  Toggle GUI / HUD
F2 or C            =  Capture Screenshot
Drag & Drop        =  Insert Image, Save, or Stamp
Paste              =  Insert Image, Save, or Stamp
Ctrl + S           =  Open Save Prompt
Ctrl + Shift + S   =  Instant Save
Ctrl + O           =  Load Save
Ctrl + Shift + O   =  Reload Last Save
Escape             =  Cancel Action / Close Menu / Clear Logs
;                  =  Replace Mode
Shift + Mid Click  =  Pick Element with Properties
Shift + Button     =  Extra Manual Element Controls (Shift-Select)
Mid Click + Button =  Extra Manual Element Controls (Shift-Select)
Right Click        =  Open Info (on Element or Category Buttons)
Z                  =  Select Secondary Element
Backspace          =  Select Previous Element
Ctrl + Z           =  Undo
Ctrl + Shift + Z   =  Redo
Ctrl + Y           =  Redo
Shift + <          =  Decrease Speed (TPS)
Shift + >          =  Increase Speed (TPS)
G                  =  Show Grid / Decrement Grid Size
Shift + G          =  Show Grid / Increment Grid Size
Alt + Left Click   =  Start Selection
Ctrl + C           =  Copy Selection
Ctrl + X           =  Cut Selection
Ctrl + V           =  Paste Selection
Ctrl + Shift + V   =  Paste Multiple Times
Ctrl + M           =  Move Selection (Cut & Paste)
Ctrl + D           =  Duplicate Selection (Copy & Paste)
Ctrl + Backspace   =  Erase Selection
Escape             =  Cancel Selection
Right Click        =  Cancel Paste
X                  =  Horizontal Flip Paste
Y                  =  Vertical Flip Paste
Ctrl + <           =  Rotate Paste Counterclockwise
Ctrl + >           =  Rotate Paste Clockwise

(Alt/Option can be used in place of Shift)

[Button Info]
↑               =  Toggle Shift for line drawing and intensified tools (Mobile only)
Pause           =  Pause/play the simulation
>               =  Run a single frame of simulation
Minus           =  Decrease the cursor size
Plus            =  Increase the cursor size
Reset           =  Clear the entire simulation
Replace         =  Override existing pixels when placing
Elem            =  Select any element by name
Edit            =  Switch to Edit Mode and show editing tools
Info            =  Open the element info screen
Saves           =  Open the Save & Load menu
Mods            =  Open the Mod Manager
Settings        =  Open the Settings Menu
